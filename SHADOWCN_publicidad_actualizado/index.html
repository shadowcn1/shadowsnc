Integración con FaucetPay

CONFIGURACIÓN PENDIENTE
1. Activá Merchant API
Solicitá acceso desde tu cuenta FaucetPay para recibir pagos de usuarios.
2. Prepará un backend seguro
Netlify puede alojar funciones serverless. Las claves API van como variables secretas del servidor, nunca en index.html ni en el navegador.
3. Confirmá cada pago
El servidor debe verificar el callback/token con FaucetPay antes de acreditar SNC y evitar procesar dos veces el mismo pedido.
4. Retiros
Se procesan desde el servidor con saldo real suficiente, límites, verificación de usuario y registro de transacciones.
